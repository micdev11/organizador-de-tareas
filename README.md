## Installation

```bash
  pip install -r requirements.txt
```

```bash
  python manage.py migrate
```

```bash
  python manage.py runserver
```
### Create and activate a virtual environment (recommended):

```bash
  python -m venv venv
```
#### En Windows:
```bash
  venv\Scripts\activate
```
#### En Linux/Mac:
```bash
  source venv/bin/activate
```
